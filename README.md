# Play With Ray — Local Multiplayer Game

لعبة جماعية تعمل على شبكة Wi-Fi المحلية. شاشة اللابتوب تعرض لوحة التحكم والنتائج، والجوال يُستخدم لإدخال الأسماء وكشف الاسم السري.

## التشغيل

1. فك ضغط الملف وافتح مجلد `Play-With-Ray` في VS Code.
2. افتح Terminal داخل المجلد وشغّل:

   ```bash
   npm run install:all
   npm run dev
   ```

3. افتح `http://localhost:5173` على اللابتوب.
4. امسح QR الظاهر لإدخال الأسماء من الجوالات. يجب أن تكون الأجهزة على شبكة Wi-Fi نفسها.

يتطلب المشروع Node.js 20 أو أحدث. إذا لم يعمل QR على الجوال، تأكد من السماح باتصالات الشبكة المحلية في جدار الحماية.

## طريقة اللعب

- يحتاج كل لاعب إلى إدخال 5 أسماء على الأقل قبل بدء اللعبة.
- يرفض الخادم أي اسم مكرر في اللعبة، حتى لو أُرسل بحروف كبيرة أو صغيرة مختلفة أو ضمن دفعة الأسماء نفسها.
- كشف الاسم من الجوال يبدأ مؤقت الـ25 ثانية المتزامن على شاشة اللابتوب.
- أزرار لوحة النتائج تتيح لمدير اللعبة منح نقاط التخمين أو خصم 100 نقطة عند الغش.
- يستطيع كل لاعب تخطي دوره مرة واحدة في كل جولة. يتحقق الخادم من الحد ويعيده عند الانتقال إلى جولة جديدة.
- بعد انتهاء الأسماء، زر «لعبة جديدة» يعيد اللعبة إلى الإعدادات، ويحتفظ بقائمة اللاعبين مع تصفير النقاط وإفراغ الأسماء لتسجيل مجموعة جديدة.

## الحفظ وإعادة تشغيل الخادم

يحفظ الخادم الحالة تلقائياً في `server/data/game.json`. إذا أُعيد تشغيل الخادم بعد انتهاء اللعبة، يعيدها إلى إعداد لعبة جديدة مع الاحتفاظ باللاعبين وتصفير النقاط، بدل إبقائها على شاشة النهاية. أثناء لعبة نشطة، تُستعاد الحالة المحفوظة عند إعادة التشغيل.

## نشر اللعبة برابط عام

المشروع يتضمن إعداد Render في `render.yaml` ليقدم واجهة اللعبة وخادم Socket.IO من الرابط نفسه. النشر المجاني يحتاج حسابًا في Render وGitHub، ومشروع PostgreSQL مجاني في Supabase حتى تبقى بيانات اللعبة بعد إعادة تشغيل الخدمة.

1. ارفع مجلد المشروع إلى مستودع GitHub خاص.
2. أنشئ مشروعًا مجانيًا في Supabase، ثم انسخ رابط PostgreSQL من إعدادات الاتصال (استخدم رابط الاتصال الذي يطلب SSL).
3. في Render اختر إنشاء خدمة من ملف Blueprint واربط مستودع GitHub.
4. عند طلب `DATABASE_URL`، الصق رابط قاعدة البيانات في متغير البيئة السري، ثم ابدأ النشر.
5. بعد اكتمال النشر، افتح رابط `onrender.com` الذي يوفره Render. سيعمل QR على الرابط العام تلقائيًا.

الخطة المجانية مناسبة للعبة تجريبية، لكن خدمة Render تنام عند الخمول وقد تتأخر أول استجابة بعد ذلك. مشروع Supabase المجاني قد يتوقف بعد أسبوع من قلة النشاط؛ يمكن استعادته من لوحة Supabase. لا تضع رابط قاعدة البيانات في ملفات المشروع أو ترسله للّاعبين.
